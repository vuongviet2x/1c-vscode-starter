# Thư mục skill

Skill **1c-dev-mentor-student** do giảng viên gửi riêng (file ZIP), **không** nằm trong repo này.

Cài bằng một lệnh, chạy trong terminal của VS Code tại thư mục dự án:

- Windows: `scripts\windows\install-skill.cmd "%USERPROFILE%\Downloads\1c-dev-mentor-student.zip"`
- macOS: `./scripts/macos/install-skill.sh ~/Downloads/1c-dev-mentor-student.zip`

Sau khi cài, thư mục này sẽ có `1c-dev-mentor-student/SKILL.md`. Git đã được cấu hình để bỏ qua thư mục skill, nên bạn không vô tình đẩy nó lên GitHub.
